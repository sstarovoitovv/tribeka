## Подтверждено на основном домене

Главная, about, contacts и страница услуги возвращают 200. Несуществующий URL и закрытая PHP-библиотека возвращают 404. HTTPS www перенаправляет 301 на apex, сохраняя путь и параметры. Проверены CSP, HSTS, nosniff, frame/referrer/permissions headers. OPTIONS формы возвращает 204 и актуальный X-Tribeka-Release. Содержимое about видно без JavaScript.

Chrome подтвердил фактически отрисованный Manrope-ExtraBold, opacity страницы 1 и видимую нижнюю мобильную навигацию. Ошибок JavaScript при просмотре главной не обнаружено. Сохранены палитра, карта и заглушки. Убрана анимация прозрачности, из-за которой предыдущие снимки выглядели тускло. Кнопки и иконки остаются текстом/SVG. Для более чёткого растрового логотипа нужен исходный SVG или экспорт PNG достаточного размера; увеличение маленького исходника деталей не добавляет.
