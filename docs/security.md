# Безопасность

## HTTP

Публичный endpoint — `POST /api/request.php`; `OPTIONS` обслуживает CORS preflight. Остальные PHP-пути и неизвестные URL возвращают 404. `public/.htaccess` запрещает листинг и доступ к исходникам и служебным файлам, устанавливает CSP, HSTS, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy` и `Permissions-Policy`. CSP допускает фреймы Яндекс Карт. CORS разрешает только настроенные origins и не заменяет серверную валидацию.

## Заявки и файлы

Обработчик проверяет UTF-8, длины полей, телефон, согласие и версии документов. Из URL источника сохраняются только origin и path. PDO prepared statements записывают заявку и метаданные вложений в одной транзакции; при ошибке файлы этой заявки удаляются.

Допускаются до пяти файлов, 15 MiB суммарно. Проверяются статус HTTP-upload, расширение, MIME, сигнатура и размер. Вложения получают случайные имена и SHA-256, хранятся вне web root и не распаковываются. Проверка формата не подтверждает отсутствие вредоносного содержимого.

## Ограничения запросов

Одна попытка с IP за 30 секунд; резервирование счётчика выполняется через `flock` до проверки полей. Превышение возвращает `429` с `Retry-After`, ошибка состояния лимита — `503`. Используется `REMOTE_ADDR`; за proxy необходимо корректно передавать реальный IP от доверенного узла.

Запись и очистка заявок используют shared maintenance lock, backup — exclusive lock. Во время резервного копирования форма может получить `503` с `Retry-After`.

## Антивирус

`public/api/_lib/attachment-scanner.php` запускает ClamAV до сохранения вложений. Параметры `antivirus` в серверной конфигурации: `enabled`, абсолютные пути `binary` и `database_dir`, `timeout_seconds` (1–120). Файлы проверяются одним процессом; аргументы передаются в `proc_open` без shell.

При включении требуется база не старше семи дней. Угроза возвращает `422`; недоступность сканера, устаревшая база или timeout — `503`. Зашифрованные документы, макросы, повреждённые контейнеры и превышение пределов сканирования отклоняются. Заявки без вложений не зависят от сканера.

**Эксплуатационное ограничение:** на последней проверке 19.10.2026 production-сканер был выключен: база датирована 14.07.2021, обновление возвращало HTTP 403. Перед включением необходимы актуальная база и проверка ресурсов хостинга; иначе загрузки будут отклоняться.

## Проверки

`npm run test:php` проверяет валидацию, вложения, SQL и конкурентный rate limit на изолированных данных. Fixture сканера проверяет обработку вердиктов и ошибок, но не заменяет приёмку ClamAV на сервере. `npm run test:apache` проверяет HTTP-правила. Резервное копирование и восстановление описаны в [operations.md](operations.md).
